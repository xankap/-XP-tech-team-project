# Configure the Google Maps key without committing it

A Google Maps key used by a mobile app is present in the compiled app at runtime; it cannot be made truly secret from a determined app user. Protect it with Google Cloud restrictions: Android application restriction (package name + SHA-1 signing certificate), and API restriction to **Maps SDK for Android**. Use a separate key for each environment and configure billing/quotas.

## 1. Store the key locally

Create `android/local.properties` (already ignored by `.gitignore`) and add:

```properties
sdk.dir=/your/android/sdk/path
MAPS_API_KEY=YOUR_RESTRICTED_ANDROID_MAPS_KEY
```

Keep the existing `sdk.dir` generated by Android Studio; add only the `MAPS_API_KEY` line. Never commit this file.

## 2. Pass the key to the Android manifest

In `android/app/build.gradle` (Groovy), read `local.properties` and add a manifest placeholder:

```groovy
import java.util.Properties
import java.io.FileInputStream

 def localProperties = new Properties()
 def localPropertiesFile = rootProject.file('local.properties')
 if (localPropertiesFile.exists()) {
     localProperties.load(new FileInputStream(localPropertiesFile))
 }
 def mapsApiKey = localProperties.getProperty('MAPS_API_KEY', '')

 android {
     defaultConfig {
         manifestPlaceholders = [MAPS_API_KEY: mapsApiKey]
     }
 }
```

If `manifestPlaceholders` already exists, merge the `MAPS_API_KEY` entry rather than replacing the existing map. For Kotlin DSL (`build.gradle.kts`), use equivalent `Properties` loading and `manifestPlaceholders["MAPS_API_KEY"] = mapsApiKey` syntax.

## 3. Reference the placeholder

Inside the `<application>` element of `android/app/src/main/AndroidManifest.xml`, add:

```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="${MAPS_API_KEY}" />
```

Do not paste the literal key into the manifest. The placeholder is resolved during the Android build.

## 4. Verify

Run `flutter clean`, `flutter pub get`, then `flutter run`. If the map is blank, check package name, signing SHA-1, Maps SDK for Android enabled, billing, and logcat errors. Do not publish a key with unrestricted API access.
